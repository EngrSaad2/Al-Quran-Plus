# Al Quran Plus

Comprehensive web application and backend platform for Holy Quran reading, audio recitations, multi-language translations (English & Bengali), and notification management.

## 🌐 Live Website
- [alquranplus.com](https://alquranplus.com)

## 🛠️ Tech Stack
- **Framework:** Laravel 12
- **Language:** PHP 8.4+
- **Database:** MySQL / MariaDB
- **Frontend:** Vanilla CSS / JavaScript, Bootstrap 5, FontAwesome 6
- **Hosting:** Hostinger

## 🚀 Features
- Complete Surah & Ayah reading with crystal-clear Arabic typography
- Bengali & English translations
- High quality audio recitation integration
- Bookmarks & Juz browsing
- Notification management system & push notification infrastructure

## 🔒 Security & Deployment
- Automated deployment via `deploy.py` / GitHub sync.
- Production `.env` and sensitive files are strictly excluded from source control.
